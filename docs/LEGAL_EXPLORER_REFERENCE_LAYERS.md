# Preserved Legal Explorer Reference Layers

Current canonical graph breadth does not delete or hide older governed reference libraries.

The explorer preserves and labels these layers separately:

- doctrine_registry
- doctrine_graph_edges
- legal_case_law
- litigation_barriers
- legal_weak_joints
- claim_element_matrix
- proof_frameworks
- workflow_master / workflow_steps / deadline_rules as legacy reference counts only

Current civic-object graph nodes remain current canonical objects. Reference records remain reference records. The explorer may display and cross-navigate both, but it must not silently merge identities or reclassify a reference record as a current civic object.
