# Legal & Doctrine Explorer Scope

The Doctrine Graph is not a 15-doctrine demo.

Its current explorer contract exposes the largest safely browsable current civic/legal universe while preserving type truth:

- every current graph node remains reachable through whole-universe page readers;
- the default legal/civic explorer scope includes legal authorities, workflows, enforcement pathways, agencies, oversight routes/bodies, deadlines, policy alerts/patterns, organizations, resources, programs, and contacts;
- doctrine_registry remains a doctrine reference layer rather than a boundary on graph size;
- legal_case_law, litigation_barriers, legal_weak_joints, claim_element_matrix, and proof_frameworks remain visible governed reference layers;
- browser graph windows are rendering/transport windows only and must never be presented as universe size;
- type, jurisdiction, and text filters narrow the full universe deterministically;
- source and canonical types are never silently relabeled merely to increase doctrine counts.

The UI must explicitly distinguish `window` from `universe`.
