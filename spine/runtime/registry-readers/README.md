# Registry Readers

## Purpose

Registry readers are the canonical access layer between runtime circulation and the governed substrate.

Registry readers prevent:
- duplicate data access patterns
- hidden ontology forks
- parallel procedural truth systems
- UI-only runtime logic
- ungoverned substrate access

---

# Canonical Responsibility

Registry readers:
- read canonical registries
- preserve provenance continuity
- preserve deterministic lineage
- preserve replayability
- preserve constitutional observability
- expose explicit uncertainty

Registry readers never:
- mutate canonical truth silently
- reinterpret substrate reality invisibly
- create hidden procedural state
- fork ontology definitions
