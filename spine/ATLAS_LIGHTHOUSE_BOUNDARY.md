# Atlas ↔ Lighthouse Boundary Doctrine

## Purpose

This document defines the canonical architectural boundary between Atlas and Lighthouse.

The purpose of this boundary is to:
- prevent duplicate ontology systems
- prevent parallel governance layers
- prevent substrate fragmentation
- preserve deterministic procedural continuity
- preserve constitutional runtime integrity

---

# Core Separation

- upstream ingestion
- normalization
- entity formation
- signal formation
- jurisdiction overlay generation
- structural observation
- production view generation

Atlas observes reality.

Atlas is the population and observation engine.

Atlas is infrastructural.

Atlas is NOT:
- a civic environment
- a room system
- a constitutional runtime world
- a procedural navigation layer
- a duplicate Spine

---

## Lighthouse

Lighthouse is:
- the governed civic-operating environment
- constitutional observability infrastructure
- procedural topology space
- navigable civic reality
- environmental cognition architecture

Lighthouse contextualizes and governs procedural reality.

The Spine belongs to Lighthouse.
