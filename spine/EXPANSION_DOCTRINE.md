# Expansion Doctrine

## Core Principle

Expansion occurs outward from the governed substrate.

Expansion must never create:
- duplicate ontologies
- parallel procedural systems
- hidden governance layers
- isolated execution worlds
- semantic fracture
- duplicate constitutional substrates

---

# Expansion Law

All future domains, rooms, overlays, pathways, engines, and civic environments must attach to:

- the Spine
- canonical registries
- constitutional runtime governance
- provenance continuity
- deterministic execution lineage

The substrate remains singular.

---

# Expansion Direction

Expansion flows:

```text
substrate
  ↓
rooms
  ↓
pathways
  ↓
overlays
  ↓
operational domains
```

NOT:

```text
new worlds
new ontologies
new procedural universes
```

---

# Universal + Overlay Scaling Doctrine

The ecosystem scales through:

Universal Procedural Layer
+
Jurisdiction Adaptation Overlay
+
Domain Adaptation Overlay

Meaning:
- core procedural truth remains canonical
- local variation becomes overlay infrastructure
- new domains become governed extensions
- portability remains preserved
- replayability remains preserved
