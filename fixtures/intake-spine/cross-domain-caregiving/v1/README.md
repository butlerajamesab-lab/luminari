# Cross-Domain Caregiving Universal Intake Fixture v1

## Boundary

This is a public-safe, de-identified contract fixture for the Universal Lighthouse Intake Spine. It was derived from a complex real-world scenario, but it contains no original source files, identifying names, facility identity, contact information, or verbatim private messages.

The fixture is not an elder-care schema. It tests whether the same universal spine can carry a cross-domain record involving care continuity, healthcare, benefits, housing and home stability, insurance, transportation, administrative process, and user capacity.

## Included

- `cross_domain_caregiving_intake_fixture.v1.json.gz.b64` — gzip-compressed, Base64-encoded portable golden-master fixture.
- `cross_domain_caregiving_intake_fixture.v1.ts` — Node loader and TypeScript export.
- `cross_domain_caregiving_intake_fixture.v1.schema.json` — top-level validation schema.
- `cross_domain_caregiving_intake_fixture.contract.ts` — adapter-driven Vitest contract registration. It is intentionally not named `*.test.ts` because the runtime adapter is supplied by the implementation under test.

## Core assertions

- Stabilization precedes extraction burden.
- Chronology precedes conclusions.
- Evidence tiers remain distinct.
- Missing primary sources remain visible.
- Authority-dependent rights remain pending until authority is proven.
- Cascades reference chronology.
- Multiple capacity-aware action paths are produced.
- Later urgent events reopen stabilization.
- Identical inputs and declared versions produce the same fingerprint.
- No case-specific vocabulary expands the universal contract.

## Privacy

Do not add the original private source assets to this public repository. Restricted source records belong only in an authorized evidence store.
